Reports a DTF task that nothing ever starts.

A task counts as started when the framework runs it on a cron - @TaskSchedule or a non-empty cron in its task-properties block - or when production code schedules it, directly or through a project wrapper.

Not counted:

  • A schedule written in the task itself or in its abstract base: a task rescheduling itself, or the body of a schedule(message) helper, runs only once something else has started it. Calls to such a helper from other code do count.
  • Calls from test sources. A task scheduled only from tests is reported as such. A task that is itself test code may be scheduled from tests.

A task launched from another application cannot be seen from here; suppress the warning on its class.

Example:


public class CleanupTask implements Task<String> {
    public static final TaskDef<String> CLEANUP = TaskDef.privateTaskDef("CLEANUP", String.class);

    @Override
    public TaskDef<String> getDef() { return CLEANUP; }
}

Nothing passes CLEANUP to schedule(...), so the class name is reported.
